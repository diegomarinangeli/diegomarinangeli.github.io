EVO-X

PLSQL

Interactive 3D cyberpunk experience built in Unreal Engine 5, developed as the exam project for Web3D & Interactive Cinema (University of Camerino, A.Y. 2025/26) by Diego Marinangeli.

Requirements

  • Windows 10/11 (64-bit)
  • DirectX 12 compatible GPU

How to run

The two largest files (UnrealGame-Win64-Shipping.exe and EvoXProject-Windows.ucas) are tracked with Git LFS. GitHub's "Download ZIP" does not download their real content — you'll get tiny text placeholders instead, and the game won't start. Use one of these instead:

  • Install the Git LFS client, then run git lfs install once.
  • Clone the repository normally: git clone https://github.com/diegomarinangeli/web3d.git — Git LFS will fetch the real files automatically during clone.
  • If you already cloned/downloaded before installing Git LFS, run git lfs pull inside the repo to fetch the real files.
  • Keep the folder structure intact: EvoXProject.exe must stay next to the Engine/ and EvoXProject/ folders.
  • Run EvoXPackage/EvoXProject.exe.
